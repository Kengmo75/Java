In this repository, we will see and understand how Java is used to identify, analyze and solve problems.  
The first file called EcommerceSystem, the java code creates a simple Ecommerce System for an online store.
The online store has three entities, product and customers belong to the com.ecommerce package while orders belongs to a com.ecommerce.orders package
The Main java combines all packages and runs returning the OrderID, Customer Name and TotalAmount purchased.

The second file on the other hand called: TextAnalysisTool prompts a user to enter a lengthy text, after which the text ic analyzed to detect the total number of characters, unique characters and so many other interesting things.
